# MB85RC v1.1.1

Patch release focused on bringup CLI polish and release documentation alignment.

## Highlights

- Successful diagnostic/demo commands now use compact pass/fail output instead of verbose `Status: OK` blocks.
- Stress progress keeps color on the success/fail counters only.
- Stress summary labels distinguish user-visible cycles/commands from tracked I2C health transactions.
- Serial command handling uses the shared bounded CLI shell helper for cleaner monitor logs.
- The `stress` parser now rejects typo-like prefixes instead of treating them as malformed stress counts.
- Public Doxygen comments are complete for `SettingsSnapshot` and clarify latched-`OFFLINE` use of `BUSY`.

## Included In This Release

### Changed
- `stress` throughput is reported as cycles per second.
- `stress_mix` throughput is reported as commands per second.
- Health deltas in stress summaries are labeled as tracked I2C health deltas.
- `randbench` restore and `typed_demo` write/restore paths print compact `[PASS]` lines on success and detailed `Status` blocks only on failure.
- `stress` command recognition now matches the documented `stress [N]` grammar.

### Documentation
- README stable release, installation tag, release highlights, and example command descriptions updated for `v1.1.1`.
- Changelog includes the dated `v1.1.1` patch entry.
- Doxygen project metadata updated for release `1.1.1`.
- Added the missing `v1.1.0` release summary.
